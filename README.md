
# Water Leakage Detection Using Machine Learning

An end-to-end machine learning application that predicts
possible water leakage from pipeline operational parameters.

## Features
- Pipeline parameter input
- Machine learning based prediction
- Streamlit web interface

## Technologies
- Python
- Pandas and NumPy
- Scikit-learn
- Streamlit
- Joblib

## Run locally

Install dependencies:

pip install -r requirements.txt

Start the application:

streamlit run app.py

## Model
The application uses a trained machine learning model
and its metadata file.

## Disclaimer
Predictions are indicative and do not replace
physical pipeline inspection.
